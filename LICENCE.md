## 🧩 About

**Medieval Dynasty Companion** is a curated list of Medieval Dynasty open-source tools:

- **Overlays** — on-screen helpers, layout notes, inventory viewer, quick-craft panel
- **Quality-of-Life Helpers** — building planner, crop rotation notes, NPC schedule tracker
- **Research Notes** — dynasty management layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

## ✨ Features

### ESP
- Quick-Craft Panel — craft items from a shortcut menu
- Inventory Viewer — overlay showing carried items and weights
- NPC Schedule Tracker — view villager routines
- Time Scale Control — adjust day length for study (0.5x to 5x)

### Wallhack
- Building Planner — preview placement footprints
- Resource Highlighter — highlight nearby gatherables
- Crop Rotation Notes — plan fields efficiently

### Aimbot
- Map Overlay — mark points of interest
- Compass Helper — show direction to key locations
- Fast Travel Notes — record discovered paths
